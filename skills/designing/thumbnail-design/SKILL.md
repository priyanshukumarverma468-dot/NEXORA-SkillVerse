# Thumbnail design

## Description
Design a clear thumbnail composition with strong focal hierarchy and small-screen legibility.

Install or use the official web/desktop editor and import only licensed assets. Set the target export size, color profile and platform constraints before production.

## Step-by-step workflow
1. Record audience, primary task, platform, dimensions, content constraints, brand rules and delivery formats.
2. Map hierarchy and interaction states (including loading, empty, error, focus and disabled states where relevant).
3. Build a responsive/accessibility-aware prototype using consistent spacing, typography, contrast and non-color cues.
4. Review at real target sizes and with keyboard/assistive-technology considerations; get stakeholder approval for subjective choices.
5. Export editable source plus named assets and document dimensions, fonts, colors, licensing and handoff assumptions.

### Design workflow
Use an appropriate design tool such as Figma, Penpot, Inkscape or a platform-native editor; verify the current license and export requirements.

## Practical example
**Task:** Export two thumbnail concepts and compare them at actual display size.

1. Create a small low-fidelity layout first, naming the target platform, dimensions, audience, primary action and asset rights.
2. Produce the example as an editable component/frame; include focus, error, empty and disabled states where the interface needs them.
3. Preview at the smallest target size and check contrast, keyboard order, text scaling and meaning that is not conveyed by color alone.
4. Export an editable source and optimized deliverable; record size, color profile, font/asset licenses and handoff notes.
